# Projeto-Locus
Projeto de Final de Curso de Engenharia de Software em dupla: uma plataforma web para anotações e revisões de estudo.

Objetivo geral

O objetivo geral do Locus é desenvolver uma Plataforma Web de apoio ao estudo que permita, ao estudante, o registro, a organização e a revisão de conteúdos utilizando diferentes recursos de anotação e estratégias de aprendizagem pautadas em evidências científicas.
