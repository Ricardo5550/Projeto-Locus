# Projeto-Locus
Projeto de Final de Curso de Engenharia de Software em dupla: uma plataforma web para anotações e revisões de estudo.

# 1 - Objetivo

O principal objetivo do Locus é desenvolver uma plataforma web de apoio ao estudo que permita, ao estudante, o registro, a organização e a revisão de conteúdos utilizando diferentes recursos de anotação e estratégias de aprendizagem pautadas em evidências científicas, relacionando os conteúdos com os recursos e as estratégias.

# 2 - Ferramentas e Tecnologias

- Front-End: linguagens CSS e TypeScript, bibliotecas Tiptap, React e React Flow.
- Back-End: linguagem Python e frameworks Django e Django REST.
- Banco de Dados: PostgreSQL.
- API externa: Crossref REST API.
- Ferramentas: Render, Figma, Visual Studio Code e Vite.
